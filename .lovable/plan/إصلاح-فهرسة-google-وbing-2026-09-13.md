# إصلاح فهرسة Google وBing

## النتيجة المطلوبة
- جعل خريطة الموقع قابلة للقراءة باستمرار ومتطابقة مع الروابط الفعلية.
- إزالة الإشارات المربكة لمحركات البحث وتحسين اكتشاف المقالات الجديدة.
- التحقق من ملفات إثبات Bing وIndexNow ومسارات الصفحات المنشورة.

## التنفيذ
1. توحيد مصدر خريطة الموقع التي تُنشأ عند النشر، مع إدراج الصفحات العامة والمقالات فقط.
2. إزالة تواريخ `lastmod` المصطنعة من الصفحات الثابتة، واستخدام تاريخ المقال الحقيقي فقط عند توفره.
3. تبسيط `robots.txt` ليشير إلى `sitemap.xml` و` sitemap-news.xml` فقط، دون تقديم Atom كخريطة موقع.
4. توحيد الروابط النهائية ذات الشرطة المائلة بين الخريطة، الصفحات المسبقة الإنشاء، والوسوم الأساسية.
5. الحفاظ على ملف تحقق Bing ومفتاح IndexNow، ثم اختبار XML وعينة من الروابط والبناء النهائي.

## ملاحظة مهمة
النطاق يعمل حالياً عبر GitHub Pages وليس مرتبطاً بنشر Lovable. الإصلاحات ستصل إلى `prophetic.pw` بعد دفعها وتشغيل مسار النشر الحالي. بيانات Search Console المباشرة غير متاحة لهذا المشروع، لذلك سأعتمد على الفحص الحي للملفات والاستجابات ولا أدّعي أن Google أو Bing ضمنا الفهرسة.

## التفاصيل التقنية
- المصدر الأساسي: `scripts/generate-ssg.mjs`.
- التحقق: XML صالح، HTTP 200، نوع محتوى XML، روابط فريدة، وعدم وجود تواريخ تحديث آلية مضللة.
